# Project instructions

- Run this project directly with Node.js and local/server PostgreSQL and Redis. Do not use Docker.
- After completing requested changes, run relevant checks, create a focused commit, and push to `origin/main`. The user has authorized this workflow for future completed work.
- Preserve existing Git history; never force-push or discard unrelated local changes.
- Never commit `.env`, credentials, `storage`, logs, generated videos, `node_modules`, or `dist`.
- Keep mock providers, manual approval, and private YouTube uploads as defaults. Clearly distinguish mock tests from live API verification.
- Follow the setup and validation commands in `README.md`.
